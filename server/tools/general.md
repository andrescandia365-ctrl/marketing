# Otra herramienta (general)

Last checked: 2 Oct 2026

Use when the image or video tool has no file of its own yet. These are safe defaults, not facts about a specific tool.

## How to write prompts

- Image prompt: one paragraph, 40 to 90 words. Subject → action → place → time and light → lens and framing → style. It must stand alone, so include the style.
- End image prompts with the wanted clean state: "blank labels, bare walls, no signage, no lettering". All type is added on top by the app.
- Video prompt (animating the still): 25 to 60 words. Don't describe the person again. One action, one slow camera move, what stays still, then "Audio: …".
- Keep people and places consistent with one hero still per setup, and repeat a short identity line in every prompt with that person or place.

## What to avoid

- Readable text, logos, brand names, real people's likeness.
- Two actions in one short clip; fast motion; crowds.
